# Boss drops reference (OSRS Wiki)

This file documents boss drop tables and rarities for SpoopTool. **Drops that are 100% (Always) do not affect the luck meter**—only random drops with a rate &lt; 1 should move the needle.

Sources: [OSRS Wiki](https://oldschool.runescape.wiki/) (e.g. [Vorkath](https://oldschool.runescape.wiki/w/Vorkath#Post-quest)). Drop rates are estimates from the wiki / Drop Rate Project unless cited.

## Luck meter rules (recap)

- **Only random drops** (probability &lt; 1) update the luck meter.
- **Guaranteed drops** (e.g. Vorkath’s 2× superior dragon bones, 2× blue dragonhide; Araxxor’s Coagulated venom when it’s the conditional “Always” drop) are ignored: in code, `rarestProbability >= 0.99` or `=== 1` skips the update.
- **Common drops (1/32 or better):** Any drop with rate **1/32 or more common** (expected kills ≤ 32) is always treated as **normal** and does **not** move the luck meter. Only rarer drops (1/33 and below) can affect luck.
- **Rarity tiers** (scale the luck delta by how rare the drop is):
  - **1/100–1/500 (medium):** base delta only.
  - **1/500–1/1500 (high):** +1 for lucky, -1 for unlucky (on top of base).
  - **1/1500+ (extreme):** +2 for lucky, -2 for unlucky (on top of base).
- When Dink sends `rarestProbability` for a kill, we compute expected kills; if expected ≤ 32 or probability ≥ 0.99, we do not change the meter. The loot table Luck column shows the actual change applied, e.g. **(+4)** or **(-3)**.

## Adding more bosses

To add another boss, add a section like:

```markdown
## Boss Name
*Source: [Boss Name – OSRS Wiki](URL)*

### 100% (Always) — do **not** count for luck meter
| Item | Qty | Rarity |
| ... |

### Random drops
| Item | Qty | Rarity | ~1 in |
| ... |
```

Use the wiki’s drop table and convert “Rarity” to a rough “1 in N” where applicable.
